# KidsPlay

오래된 컴퓨터도 아이 전용 교육용 게임기로 바꿔 주는 웹 기반 키즈 게임 플랫폼입니다. 설치 없이 브라우저에서 실행되며, 한 번 접속한 뒤에는 오프라인에서도 사용할 수 있습니다.

## 포함된 놀이

- 색칠하기, 퍼즐, 같은 그림 찾기
- 알파벳, 숫자, 동물, 탈것
- 공룡, 모양, 그림 맞추기

연령(2~3세, 4~5세, 6~7세)에 따라 게임 난이도가 조절됩니다. 별과 스티커, 진행 기록, 언어와 부모 설정은 현재 기기에 저장됩니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증용 명령은 다음과 같습니다.

```bash
npm test
npm run lint
```

## 부모 모드

기본 부모 PIN은 `2580`입니다. 키즈 모드에서 화면 위쪽 모서리의 자물쇠를 3초간 누른 뒤 PIN을 입력하면 부모 화면으로 돌아갑니다. 처음 사용하기 전에 부모 화면에서 PIN을 변경할 수 있습니다.
